# NEMT 1.1.0

- Add optional resizable/fullscreen toolset editors, proportional Cab Editor rendering, adaptive Activity Editor panels and wheel zoom.
- Fix resized Route Editor picking and compass placement; add free tool windows, configurable camera key swaps and unlimited mouse panning.
- Work around the observed Route Editor audio-idle slowdown without editing routes. Keep main-game borderless behavior out of toolset and retain verbose toolset loading messages.
- Add crawl upright rotation, local-axis steering, a configurable derail shortcut and an expanded F5 HUD. Retain friction reduction and provide a default-off world-relative counter-tilt option.
- Add widescreen cab-dial correction, optional background audio, red-signal continuation, startup movie skipping and experimental corrected uncapped timing.
- Expand optional deep logging with local timestamps, activity-load tracing, audio/graphics initialization results and flushed crash-survivable records.
- Guard failed Direct3D7 device creation before native pointer use, log device results, and distinguish application-visible OS version from registry metadata.
- Add a default-off detected P-core scheduling preference with conservative fallback and preserved existing restrictions.
- Refresh the main-game welcome, release title and credits. Add bottom form padding and conditional widescreen download/install help.
- Expand user and technical documentation with findings, workarounds, diagrams and validation limits.

See the [release technical overview](../docs/technical/release-1.1.0.md) and [user guide](../docs/README.md). Settings take effect after restarting MSTS. Supported game executables remain unchanged; existing widescreen/LAA modifications are preserved. Uncapped timing remains potentially unstable.

- Graphics troubleshooting follow-up: trace probe surface creation, actual surface properties and owner; show a one-time non-pixel-format device failure warning instead of leaving the user with no explanation. The underlying laptop INVALIDOBJECT failure remains under investigation.

- Experimental targeted compatibility retry: a null-device INVALIDOBJECT on the initial graphics capability probe enters the existing 16x16 off-screen fallback. Repeated failure exits through normal cleanup; successful startup on affected laptops remains unverified.

- Add an in-game note for stock resolution selections above 2048 pixels, a refresh-rate cap beside Unlock FPS, and explicit high-disk-usage wording for deep logging. Select All no longer enables deep logging. See [display option behavior and validation](../docs/technical/display-options.md).
