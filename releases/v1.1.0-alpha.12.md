# NEMT 1.1.0-alpha.12 — Route Editor keys and cab cursor

- Add **Swap arrow keys with WASDEQ controls in route editor**, with six configurable `RE_CAM_*` bindings in `[Editors]` of `settings.ini`.
- Move the configured keys' existing shortcuts onto the corresponding arrows or Ctrl+Up/Down. Preserve Shift speed, Ctrl+letter commands and ordinary text-field input.
- Preserve custom camera bindings when applying options; extend the patcher layout for the added checkbox.
- Correct Cab Editor cursor positioning when selecting an instrument in a resized or fullscreen cab view, retaining the centered 4:3 fit.

See the [editor guide](../docs/editors.md) for settings and supported key names, and [implementation and validation](../docs/technical/editors.md) for checks. Apply with MSTS closed and restart it. All game changes apply in memory; train.exe remains unchanged.
