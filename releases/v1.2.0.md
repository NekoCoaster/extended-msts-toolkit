# NEMT 1.2.0

## What's new

- A lightweight native Windows control panel replaces the PowerShell frontend. Normal builds work offline with the included compiler.
- Choose which display hosts the borderless game window. The selection is saved, falls back to the primary display if disconnected, and stays anchored through menu and simulator transitions.
- Enable integrated high-resolution support for displays exceeding 2048 pixels in either dimension. NEMT provides clearer guidance and detects existing D3D wrappers, including D3DIM700.DLL, without overwriting them.
- Run the simulator without a physical mouse connected: a targeted DirectInput compatibility fix allows normal mouse-device creation while preserving actual input behavior.
- Clearer option labels, an aligned monitor-refresh-rate FPS cap, and saved-settings messages that reflect the selected window mode.

## Launch behavior

Borderless mode defaults to windowed unless an explicit fullscreen resolution is supplied. With borderless disabled, NEMT leaves MSTS's normal launch mode alone; use `-vm:w` for a framed window. Apply settings and restart MSTS.

The experimental in-game high-resolution message injection and resolution-change hooks have been removed in favor of control-panel guidance and integrated support.

## Compatibility and validation

The user confirmed control-panel operation on Windows XP, 7 and 11, standalone laptop operation without the external high-resolution DLL, stable secondary-monitor placement, and in-game clicking, dragging and activity loading without a physical mouse. Native regression tests cover installation, layout, launch arguments, display selection and guarded compatibility patches. These results do not certify every hardware or graphics-wrapper combination.

Existing supported game executables and widescreen/LAA preservation remain unchanged. Uncapped FPS remains potentially unstable. High-resolution support derives from UCyborg/LegacyD3DResolutionHack (MIT-0); attribution and compiler licensing materials are included.

For installation, extract the complete NEMT ZIP and run NEMT.exe. Keep its companion files together. Source builds use BUILD AND RUN NEMT.bat. The corresponding compiler-source archive is supplied separately with the release.
