# NEMT 1.2.4

## External camera mouse controls

- New optional **Enable TSW styled external camera mouse controls** setting.
- In tracking cameras 2 and 3, hold right-click and move the mouse to orbit
  horizontally/vertically. While holding right-click, scroll up to move closer
  or down to move farther from the train.
- Preserves native camera limits and existing keyboard controls.
- Shift+9 unlocks tracking and restores MSTS's original FPS-style right-click
  free-look. Re-enabling tracking starts a fresh drag without queued movement.
- Independent of walking mode and derailment camera unlocking; defaults off.

## Control panel

- Renamed verbose loading text to **Show verbose details in loading screen text**
  and moved it directly above **Enable deep logging**.
- **Use Recommended** now leaves both verbose loading text and deep logging off.
  Both remain individually selectable.

## Updating and validation

Close MSTS, open the updated NEMT, select the desired options, click **Apply**,
then restart MSTS. Restart alone does not install the updated runtime.

The user confirmed host mouse orbit/zoom operation and the Shift+9 free-look fix.
Native regressions cover input mapping, tracking transitions, cancellation,
settings persistence and control-panel layout. Compatibility audits retain the
Windows XP API baseline. These checks are distinct from long-session testing
across every route and input device.

See [camera controls](../docs/external-camera.md) and the
[technical record](../docs/technical/external-camera.md).
