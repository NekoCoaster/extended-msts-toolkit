# NEMT 1.1.0-alpha.15 — crawl input fix, shortcuts and manual derailment

- Fix rotational controls being discarded because MSTS has 238 keyboard entries rather than the assumed 256.
- Show the current upright/steering keyboard bindings and a live input indicator in the extended white F5 HUD.
- Add `\` to derail the controlled consist through MSTS's native derailment sequence, once per press, including from a standstill. Requires crawl mode; ignores menus, pause, lost focus and modified key combinations.
- Keep Space rolling around the locomotive's length and train brake keys steering around its own up axis.

The input correction is covered by guard-page tests using the observed game layout. The real native derail routine is tested with base and widescreen fixtures, alongside the physics, HUD and driving-readiness checks. See the [controls guide](../docs/crawl-hud.md) and [technical evidence](../docs/technical/physics.md). The native derail command and expanded white F5 HUD were also checked in a loaded MegaCoaster driving scene. Restart MSTS after updating.
