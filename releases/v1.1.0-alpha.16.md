# NEMT 1.1.0-alpha.16 — simpler crawl rotation and clearer controls

- Remove automatic counter-tilt filtering and its steering bypass. Manual upright and left/right nudges retain their own-axis behavior.
- Use the requested four-line extended F5 display, signed two-decimal force and current control labels.
- Add `[Derailment] DerailKey=BACKSLASH` in settings.ini; choose another physical key or `NONE`. Apply preserves custom bindings.
- Add the requested NEMT welcome/help message in the main game, with a wider stock footer so it fits. Editors and Tools keep their existing text.

See the [crawl guide](../docs/crawl-hud.md) and [runtime details](../docs/technical/native-runtime.md). Restart MSTS after updating or changing bindings.

Alpha.16 was checked in a loaded MegaCoaster driving scene at 640×480: all four HUD lines were visible, F12 (configured for the test) invoked native derailment, and Standby changed to Active. The main-menu paragraph and restored route-selection navigation were checked visually. The keyboard test required temporarily skipping the intro movie; the user’s original movie preference was restored afterward.
