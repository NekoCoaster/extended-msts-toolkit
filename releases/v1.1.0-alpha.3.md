# NEMT 1.1.0-alpha.3 — native alerts and quality-of-life options

Development build for host testing; stable 1.0.2 is unchanged.

- Add a cab-dial checkbox, enabled only for supported widescreen executables, with a prerequisite installation-guide link.
- Mark corrected high-FPS timing **Potentially unstable**. Record two successful initial host runs; the apparent improvement to 16× activity messages remains preliminary.
- Add optional background audio through DirectSound's secondary-buffer GLOBALFOCUS flag.
- Add red-signal continuation with MSTS's native ALERT/OK popup. Remember referenced signal objects to avoid repeated notices while they remain in the monitored list; reset on activity initialization. Other activity-ending conditions are preserved.

Automated checks cover the notification adapter, repeat suppression, native regression tests and installation across base/widescreen/LAA combinations. The earlier Windows-dialog bypass passed host testing, but the new native popup, real-route repeat suppression and audible background behavior still need [host validation](../docs/investigations/quality-host-test.md).

No runtime Frida helper, on-disk executable edits or new per-frame file writes are introduced. The notification is not a new persistent activity scoring system.
