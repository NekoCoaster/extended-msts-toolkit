# NEMT 1.1.0-alpha.13 — unrestricted Route Editor mouse panning

- Add **Remove Route Editor mouse-panning limit**, independently configurable as `[Editors] UnlimitedMousePan=true` or installer switch `-UnlimitedEditorPan`.
- Feed relative mouse movement to the free camera so rotation continues on both axes after MSTS's hidden virtual pointer reaches its bounds.
- Preserve native sensitivity, normal cursor/object-drag behavior, button transitions and focus handling. Simulator camera limits remain unchanged.
- Extend the patcher layout for the additional option.

The regression check executes MSTS's original pointer routine from base and widescreen fixtures and verifies continued camera deltas across both boundaries. See the [editor guide](../docs/editors.md) and [implementation and validation](../docs/technical/editors.md). Apply with MSTS closed and restart it. The game executable remains unchanged.
