# NEMT v1.0.2

Neko's Extended MSTS Toolkit adds configurable native improvements through `DINPUT.dll`, leaving the supported `train.exe` unchanged.

## Download and install

Download **NEMT.zip** from Assets below, extract it, then run **NEMT.vbs**. You can also drag your installed `train.exe` onto the script. Close MSTS before applying or uninstalling features.

Choose **NEMT.zip**, rather than GitHub's automatically generated source archives, for the verified ready-to-use package. **NEMT.zip.sha256** contains its SHA-256 checksum. Python and Frida are not required to use the toolkit.

## Packaging fix

Version 1.0.2 makes checksum line endings, file ordering and ZIP metadata consistent between Windows packaging and the Linux release runner. The native DLL is unchanged from 1.0.0.

## Included features

- Borderless mode for ordinary `-vm:w` launches, with centered windows and custom resolutions. Launches without display arguments default to windowed; use `-vm:WIDTH,HEIGHT,32` to request fullscreen.
- Optional FPS unlock through MSTS's existing `-noclamp` option.
- Verbose startup and activity loading details, terrain-generation job counts and estimated remaining time.
- Missing track-section dependency warnings for supported text route databases.
- Optional derailment activity-end prevention and unrestricted camera controls.
- Connected-engine crawling with 0–100× thrust, diesel/electric/steam support and wheel animation.
- Crawl status in the extended F5 HUD, with bottom-left or bottom-right anchoring.
- Optional startup logs with configurable size and backup retention.

## Changes from development builds

- Configuration is now **NEMT/settings.ini**; older configuration files are not read.
- The borderless checkbox controls `-vm:w`; the former `-vm:bw` alias is unsupported.
- The form shows its version and the NEMT repository link.
- Legacy executable migration has been removed. Restore previously patched executables with their original patcher first.
- Documentation distinguishes VM measurements, host validation and remaining investigations.

## Compatibility and validation

Supports the identified MSTS Bin **1.8.052113** original, widescreen, LAA and widescreen + LAA variants. Unknown executable changes and unrelated `DINPUT.dll` files are rejected.

Installer combinations, native argument handling, compatibility bootstrap and log rotation passed automated checks. VM startup checks covered borderless, default framed windowing and an explicit fullscreen request. Rendering wrappers can affect fullscreen presentation. In-game settings controls and cab-needle corrections are not included.
