# NEMT 1.2.2

## Fixes and improvements

- Fixed runaway tile coordinates and camera displacement when walking or noclip
  crosses a tile boundary. Walking state and camera matrices now follow MSTS's
  floating-origin shifts, with consistent F5 coordinates.
- Fixed Left Alt slow movement by sampling the physical left modifier keys within
  the focused, unpaused walking input path.
- Added configurable walking/flying speeds and Shift/Alt factors. NEMT preserves
  these settings on Apply, and extended F5 displays the configured values.
- Leaving noclip above terrain now retains vertical as well as horizontal
  velocity. Upward motion continues before gravity turns it into a fall; downward
  motion continues under gravity. Landing and below-terrain recovery still clear
  vertical velocity safely.

## Movement settings

Edit the existing `[Walking]` section in `NEMT/settings.ini` with MSTS closed:

```ini
[Walking]
WalkSpeedMps=3
FlySpeedMps=17
SprintMultiplier=2
SlowDivisor=2
```

Speed is base speed multiplied by the Shift factor when left Shift is held,
divided by the Alt factor when left Alt is held. Both factors apply together;
the default 2/2 cancels. Noclip vertical movement uses the same formula.
Speeds accept 0.01–1000 m/s; factors accept 1–100, including decimals. Invalid
values fall back individually to the defaults above, including a zero divisor.
High speeds can outpace terrain loading. See the [walking guide](../docs/walking.md).

## Updating and validation

Close MSTS, open the updated NEMT, click **Apply**, then restart MSTS. Restarting
alone does not deploy the updated runtime. Existing supported game executables
and the experimental terrain-only collision scope are unchanged.

In-game test feedback confirmed the tile-crossing fix and accepted the movement
refinements for this checkpoint. Automated coverage includes 599 movement-model
checks, 338 GUI/installer checks, native adapter tests for tile-origin shifts and
modifier input, and the existing compatibility regressions. These results do not
certify every route or extreme speed setting.
