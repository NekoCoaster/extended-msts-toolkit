# NEMT 1.1.0-alpha.1 — cab needle experiment

Development build for host comparison, not a replacement for stable 1.0.2.

- Added opt-in `[Cab] CorrectNeedleAspect=true` in the installed `NEMT/settings.ini`. It corrects rotation/scaling order for ordinary single-quad cab dial needles after the driving-scene readiness gate.
- Kept the experiment disabled by default. Reapplying the installer preserves its setting.
- Expanded the checked instruction-claim registry to accommodate the new calls alongside existing features.
- Added executable-site verification and native adapter tests, including 100,000 corrected calls and bypass checks. Existing native lifecycle, HUD, startup and window-bootstrap checks passed.

Visual validation remains pending. Follow the [comparison guide](../docs/investigations/cab-host-test.md). In-game settings controls are not included. The DLL grows from 53,760 to 55,808 bytes; no new runtime dependencies are added.
