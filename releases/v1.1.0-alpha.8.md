# NEMT 1.1.0-alpha.8 — optional movie skip and keyboard recovery

- Add **Skip startup movie** to the control panel, without registry edits, executable edits or movie-file renaming.
- Expose **Restore keyboard control after movie** as an independent checkbox, initially enabled in the form.
- Remove experimental decoder, window conversion and output-binding changes; use MSTS's original movie rendering.
- Add **Select All** beside Apply; check every enabled option while respecting prerequisites.
- Keep the compact form without a scrollbar at normal scaling and reduce the native DLL size.

See [movie options and validation](../docs/technical/startup-movie-options.md). Automated checks pass; live testing of the new skip option remains pending. The original black-picture issue is not claimed fixed. Stable 1.0.2 remains unchanged.
