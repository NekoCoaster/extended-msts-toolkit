# NEMT 1.1.0-alpha.10 — editor improvements and world-relative crawl pitch

- Keep main-game borderless mode and simulator overrides out of `-toolset`.
- Add independent options for editor resizing/fullscreen, free Route Editor tool placement and the Route Editor idle-audio slowdown fix.
- Resize Route Editor rendering surfaces and camera projection together; Activity Editor gains an expanding map and panels that fold inside when needed.
- Fit Cab Editor's cab canvas proportionally in the center, with white margins and matching mouse coordinates.
- Alt+Enter toggles borderless fullscreen in editor viewports.
- Correct crawl counter-tilt around the world-relative lateral axis, including rolled and inverted locomotives and regularized near-vertical headings.

See the [editor guide](../docs/editors.md), [editor implementation and checks](../docs/technical/editors.md) and [world-pitch investigation](../docs/investigations/world-pitch.md). All changes are applied in memory; normal installation and uninstall leave train.exe unchanged. This is a local alpha package; no release publication is implied.
