# NEMT 1.1.0-alpha.17 — optional counter-tilt

- Restore the previous world-relative counter-tilt filter as an optional crawl setting, defaulting off.
- Add **Enable counter-tilt filter while crawling (optional)** to the patcher and `CounterTilt` under `[Derailment]` in settings.ini. Apply preserves the saved choice when no override is supplied.
- Leave all three filter hook locations untouched when disabled. When enabled, manual left/right steering bypasses the filter so local-up rotation still works on the train’s side.
- Keep friction reduction, manual controls, the four-line HUD and configurable derail key unchanged.

Automated checks cover both modes, configuration and installer persistence, world-relative filtering, steering interaction, shared hook transactions and driving readiness. Restart MSTS after changing this option. See the [crawl guide](../docs/crawl-hud.md).
