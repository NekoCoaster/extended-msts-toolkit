# NEMT 1.1.0-alpha.2 — experimental high-FPS timing

Development build for host testing. Stable 1.0.2 is unchanged.

- The FPS checkbox now adds `-noclamp` and enables high-resolution elapsed-time measurement, consistent time-multiplier handling and fractional clock compensation. The label explicitly marks this option **Unstable!**
- Preserves native pause decisions, calendar rollover and unrelated clock objects. Long stalls are limited instead of being replayed as a catch-up burst.
- Retains the opt-in cab-needle correction, with positive host visual feedback. In-game settings integration has been dropped to avoid widget-addon conflicts.

Automated validation covers actual x86 clock adapters and sixteen simulated ten-minute runs across 60–1,000 FPS and 1×–16× time scales. Clock error stayed below 0.01 seconds in those cases. Cab, crawl lifecycle, HUD, startup, window-bootstrap and mutation checks passed. These are synthetic tests, not live-game timing measurements.

Follow the [host timing checks](../docs/investigations/timing-host-test.md) before treating the feature as reliable. No Frida, new per-frame disk writes or on-disk executable patches are introduced.
