# Skip the startup movie

Select **Skip startup movie (fixes keyboard control issue when loading into simulator)** in NEMT.vbs, click Apply and restart MSTS.

The game goes directly to loading. Skipping avoids the movie-related keyboard-control issue without editing the registry or renaming `GLOBAL/startup.mpg`.

Uncheck the option and Apply to return to MSTS's normal movie behavior. A movie disabled elsewhere or missing from the installation will remain disabled or unavailable. This option is a movie skip, not a video-rendering repair.
