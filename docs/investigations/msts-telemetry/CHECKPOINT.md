# MSTS telemetry discovery

Independent research, **incomplete**. Start with [the current handoff](NEW-CHAT-HANDOFF.md) and [research navigation](RESEARCH-NAVIGATION.md), then choose the relevant [coverage row](DISCOVERY-COVERAGE.md).

The catalogue contains 1,064 candidates; this is breadth, not a completion percentage. `inventory.json` retains per-candidate meanings, applicability, units, extraction, lifecycle, evidence and limitations. [INVENTORY.md](INVENTORY.md) is generated from it.

`research_index.py` provides bounded address/topic lookup over the existing local decompilation and assembly. [EXTRACTION-HANDOFF.md](EXTRACTION-HANDOFF.md) describes read safety and evidence reproduction. Raw captures and exports are preserved; the publication includes their hash manifest rather than the executable/decompiler dump.

No production NEMT integration, game-asset changes, or candidate ranking is part of this research. For historical chronology see the [archived README](README-ARCHIVE-20261010.md); its status/counts describe earlier checkpoints.
