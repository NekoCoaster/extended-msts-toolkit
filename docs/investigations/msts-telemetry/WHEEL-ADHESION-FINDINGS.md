Focused native tracing identifies three additional stored candidates. These have producer evidence, not live field/rate/slip validation. No new loaded vehicle was available for this checkpoint, and no native function was invoked.

These are distinct stored states, not duplicates of the existing externally derived `car.wheel_rotation_estimate`. They can differ across branches and producer phases. The force magnitude at engine+0x2a6 already feeds cab force channels; this checkpoint documents that relation without adding another duplicate quantity. Body/track motion, actual delivered force and wheel visual phase remain separate.

The latter selects context-definition+0x470 when current car+0x84 has bit0x100000. Otherwise weather[0x7be0d8]=1 selects context-definition+0x468, weather2 selects+0x46c, and other values select1.0. This is native weather-dependent input to the force path. It does not prove coupling from rendered precipitation particles or identify the car flag's meaning. The outer caller/context binding and live values require further validation.

0062c525 then uses the current car's definition, separately from that context definition. With definition+0x8c bit0x400000 clear, it multiplies the context result by0.4 when car+0x84 bit1 is clear, or0.2 when set, and takes the maximum with its supplied floor. With the definition bit set, it instead multiplies by car-definition+0x46c (bit1 clear) or+0x468 (bit1 set), takes the maximum with the floor, then multiplies by car-definition+0x470. The powered caller supplies approximately0.95 * engine+0x2be as that floor. The floor's control semantics and alternate call paths are not yet established.

## Context and animation consumer follow-up

It receives a context in ECX, rejects body type byte+f0 other than1, obtains the car through body+11d, and ultimately calls0062c679 with that same context and car. This is a static dispatch chain; no newly loaded object or callback execution was sampled. The broader range export in pass231 started mid-instruction and is not used as whole-range disassembly evidence; the specific five-byte thunk is independently decoded and checked by the constant mapper.

The stored+1dc phase is one additional candidate with opaque native animation units. It is not wheel angle in radians, a rendered frame number, or a guaranteed wrapped0..1 value.
