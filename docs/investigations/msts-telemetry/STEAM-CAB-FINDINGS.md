## Firebox inputs and display composition

Native debug routine0060997a reads lead+2c2 at0060bb71 and formats string771d68, `Fire temp: %.0f`. It reads lead+2ca as current fire mass, engine-definition+242 as ideal and+222 as maximum, formatting771d04, `Fire mass: %.0f Ib, ideal %.0f, max %.0f`. The font/string uses uppercase I in `Ib`; the installed Scotsman declaration supplies explicit1800lb ideal and2500lb maximum. `steam-firebox-labels.json` preserves strings and constants. This identifies mass in native pounds and temperature by name only; do not assume Celsius or Fahrenheit from plausible magnitude.

Display function0041f05c uses a30-entry colour palette. Its temperature index is the native float-to-integer conversion of `(1 - (temperature - 300)/700)*30`, minus1, then clamped0..29. Exact conversion rounding remains dependent on0041b54b. The graphic height fraction is `min((fire_mass / ideal_fire_mass)*0.75, 1)` for ordinary finite positive inputs; this is a graphic fraction, not combustion efficiency or the physical maximum-fill fraction. There is no lower clamp in the inspected branch. The routine changes drawing geometry and palette; it does not itself produce the physical fire values.
